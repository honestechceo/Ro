# RO Log

Track repair orders, flagged hours, multipoint inspections and pay, for automotive technicians.

- **Website / home-screen app:** https://honestechceo.github.io/Ro/ (`index.html`)
- **iPhone app (App Store build):** the same page wrapped with Capacitor (`ios/`, `build-ios.py`), built and uploaded to TestFlight by the **iPhone app** GitHub workflow.

The iPhone app adds: on-device text reading for RO pages and repair sheets (Apple Vision, no internet or Google key), a native VIN scanner, an **RO Log** folder in the Files app (RO files, PDFs, automatic backups), haptics and the share sheet. On the website none of that code runs.

Privacy policy: https://honestechceo.github.io/Ro/privacy.html
